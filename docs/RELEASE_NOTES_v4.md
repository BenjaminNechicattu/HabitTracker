# Habitty v4.0.0 (Android versionCode 4)

A redesign of Habitty as a modern, iPhone-style app, with a smoother mobile experience.

## What's new

### Redesigned interface
- New iPhone-inspired look across the app.
- A floating tab bar that stays in place while you scroll, so you can switch screens from anywhere.
- A simpler Today screen. The add button has been removed from the home screen.

### Better reminders
- A new scroll-style time picker for habit reminder times.
- Fixes the issue where the keyboard opened and closed when setting a reminder time on a phone.

### Add habit form
- Required-field validation when you add a habit.
- A notification explains what is missing when a habit can't be saved.

### Install as a web app
- Install prompt for Android and iPhone when you open Habitty in a mobile browser.
- Web app manifest and mobile web metadata added.
- Note: install prompts need the app to be served over HTTPS. On iPhone, use Share → Add to Home Screen.

## Release details
- App version: 4.0.0
- Android version code: 4
- Package: com.habitty.app
- Distribution: Google Play internal testing
